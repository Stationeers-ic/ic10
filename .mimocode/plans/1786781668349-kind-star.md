## Instructions to implement

| Instruction | Args | Logic |
|-------------|------|-------|
| `clamp` | `r? a(r?\|num) min(r?\|num) max(r?\|num)` | `min(max(a, min), max)` — clamp a to [min, max] |
| `rol` | `r? a(r?\|num) b(r?\|num)` | Bitwise left rotation: `((a << b) \| (a >>> (32 - b))) & 0xFFFFFFFF` |
| `ror` | `r? a(r?\|num) b(r?\|num)` | Bitwise right rotation: `((a >>> b) \| (a << (32 - b))) & 0xFFFFFFFF` |
| `sgn` | `r? a(r?\|num)` | Returns -1 if a < 0, 1 if a > 0, 0 otherwise |

## Implementation details

- `rol`/`ror`: Use `(x | 0)` for int32 conversion, `>>> 0` for unsigned, `& 0xFFFFFFFF` to mask to 32-bit. Wrap b by `b & 31` for safety.
- `clamp`: Order-agnostic: `Math.min(Math.max(a, minVal), maxVal)` — no need to verify min ≤ max.
- `sgn`: Simple ternary `a > 0 ? 1 : a < 0 ? -1 : 0`.

Each class includes `static tests()` with representative cases.
