# Fix: sp/ra aliases and missing line info in sandbox errors

## Root Cause Analysis

### Bug 1: `sp` not recognized as register

**File:** `src/Core/Chip.ts:75-76`

Built-in aliases `sp` and `ra` are stored as raw numbers:
```typescript
this.defines.set("sp", new Define("alias", this.SP));   // this.SP = 16
this.defines.set("ra", new Define("alias", this.RA));   // this.RA = 17
```

`Define.value` converts to string → `"16"`. But `getRegister()` (src/Ic10/Helpers/ArgumentParse.ts:119) expects format `rN` (regex `^r(?<reg>\d+)$`). So `"16"` doesn't match → error.

User-defined aliases via `alias` instruction (src/Ic10/Instruction/Misc/AliasInstruction.ts:74) correctly store `"r5"` format. The built-in aliases are inconsistent.

### Bug 2: Missing line/position in sandbox errors

**File:** `src/Ic10/Context/SandboxContext.ts:238-244`

`SandboxContext.addError()` overrides the base `Context.addError()` but **removes** the auto-stamp of line info from `$executeLine`:
```typescript
// Base Context.addError (line 296-313) — has auto-stamp:
if (this.$executeLine) {
    error.setLine(this.$executeLine);
}

// SandboxContext.addError — NO auto-stamp:
public override addError(error: Ic10Error): this {
    error.setContext(this);
    if (!this.$errors.has(error.id)) {
        this.$errors.set(error.id, error);
    }
    return this;
}
```

When `ErrorHandlers.handleError` in `ArgumentCalculators.ts:11-19` creates a `TypeIc10Error`, it calls `setArgument()` (sets start/length/originalText from argument) but never calls `setLine()`. In RealContext this is auto-fixed; in SandboxContext the line stays `undefined`.

## Fix Plan

### Fix 1: Store aliases with "r" prefix

**File:** `src/Core/Chip.ts:75-76`

Change:
```typescript
this.defines.set("sp", new Define("alias", this.SP));
this.defines.set("ra", new Define("alias", this.RA));
```
To:
```typescript
this.defines.set("sp", new Define("alias", `r${this.SP}`));
this.defines.set("ra", new Define("alias", `r${this.RA}`));
```

### Fix 2: Add line auto-stamp in SandboxContext.addError

**File:** `src/Ic10/Context/SandboxContext.ts:238-244`

Add the same `$executeLine` auto-stamp as the base class:
```typescript
public override addError(error: Ic10Error): this {
    error.setContext(this);
    if (this.$executeLine) {
        error.setLine(this.$executeLine);
    }
    if (!this.$errors.has(error.id)) {
        this.$errors.set(error.id, error);
    }
    return this;
}
```

### Fix 3: Add test for `move sp 0` with leading empty lines

**File:** `src/Ic10/Instruction/Misc/MoveInstruction.ts` (add to `tests()`)

Add test case:
```typescript
{
    title: "move to sp alias with leading empty lines",
    code: "\n\nmove sp 0",
    expected: [{ type: "register", register: 16, value: 0 }],
},
```
